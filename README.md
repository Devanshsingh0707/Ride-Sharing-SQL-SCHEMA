# Ride-Sharing-SQL-SCHEMA
This project is a complete SQL-based ride-sharing management system designed to simulate how platforms like Uber or Ola manage users, drivers, vehicles, rides, payments, and ratings. It includes a fully structured database schema with proper constraints, foreign keys, and relationships, along with an ER diagram and a large sample dataset of over 100 realistic entries. The SQL file also contains multiple analytical queries that extract insights such as driver performance, earnings, ride trends, active users, and pending payments. The project focuses on clean relational modeling and practical query writing, making it useful for learning database design or showcasing SQL skills.
